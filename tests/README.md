# The TUNA Test Suite

An automated check that TUNA still produces the right numbers. Run it before submitting a pull request.

## Running

From the repository root:

```
pytest                           # Everything
pytest tests/test_energies.py    # One file
```

## What is here

| File | What it covers |
| --- | --- |
| `tuna_test.py` | Path setup and the `tuna` fixture that every test uses to run calculations |
| `test_energies.py` | Total energies for HF, DFT, MP*N*, CI, coupled cluster and excited states |
| `test_invariants.py` | Relations that must hold whatever the numbers are |
| `test_input.py` | Input line parsing, keywords, error handling, and the command line |
| `test_integrals.py` | One- and two-electron integrals from the compiled extension |
| `test_properties.py` | Dipole moments, orbital energies, energy components, physical constants |
| `test_geometry.py` | Gradients, optimisation, harmonic frequencies, thermochemistry |

## Adding a test

### A new energy

Add one line to `REFERENCE_ENERGIES` in `test_energies.py`:

```python
Case("SPE : H F 0.9168 : OMP2 CC-PVDZ", -100.2245678901, source = "PySCF OMP2"),
```

The fields are the input line, the expected total energy in hartree, an optional tolerance (1e-6 by
default), an optional note saying where the number came from.

Reference energies must come from somewhere other than TUNA. If there is no convenient independent
value for the method, put the entry in `REGRESSION_ENERGIES` instead, which is for numbers that were
generated by TUNA and only prove that nothing has moved since. Promote entries out of that table as
soon as they have been checked properly.

### Anything else

Write a function whose name starts with `test_` and take `tuna` as an argument:

```python
def test_something(tuna):

    assert tuna.energy("SPE : H H 0.74 : HF STO-3G") < 0
```

The `tuna` fixture gives you:

| Call | Returns |
| --- | --- |
| `tuna.energy(line)` | Final total energy, as a float |
| `tuna.run(line)` | Energy plus the `Molecule`, the SCF `Output`, the density and the integrals |
| `tuna.calculation(line)` | The parsed `Calculation`, symbols and coordinates, without running anything |
| `tuna.gradient(line)` | Derivative of the energy with respect to bond length |
| `tuna.optimise(line)` | Optimised `Molecule` and its energy |
| `tuna.frequency(line)` | Force constant, reduced mass, frequency and zero-point energy |
| `tuna.charged_state_energies(line, charge_delta)` | Reference and charged state energies, for IP and EA |
| `tuna.command_line(line)` | Exit code and output from running `tuna.py` as a subprocess |
